# รอยจารึกธารทองแดง 3D — โคลงประพาสธารทองแดง

เกมเว็บวิชวลโนเวล 3 มิติเพื่อการเรียนรู้วรรณคดีไทยระดับมัธยมศึกษาตอนต้น เรื่อง **กาพย์ห่อโคลงประพาสธารทองแดง** พระนิพนธ์ในเจ้าฟ้าธรรมธิเบศร (เจ้าฟ้ากุ้ง)

## จุดเด่นของเกม
- **โมเดลตัวละคร 3 มิติ (Three.js + Draco GLB)**: สลับตัวละคร `เจ้าฟ้าธรรมธิเบศร` และ `เทียน` อัตโนมัติตามบทสนทนา พร้อมหมุนชมโมเดลได้ทั้งเมาส์และนิ้วสัมผัส
- **ครบทั้ง ๔ บทเรียน**:
  1. บทที่ ๑: ท่าเจ้าสนุกและถนนส่องกล้อง (ขบวนพยุหยาตรา ช้างเทพลีลา พุดตานทอง ชุมสาย)
  2. บทที่ ๒: พงไพรปริศนาลิง (งูเขียว-ตุ๊กแก และเกมแยกแยะคำพ้อง สัตว์ vs พันธุ์ไม้)
  3. บทที่ ๓: ลานรำยูงทองและไก่ฟ้า (จินตภาพสีสัน เสียง การเคลื่อนไหว และเอฟเฟกต์คืนสีสันจากขาวดำ)
  4. บทที่ ๔: ลำธารใสแห่งพระตำหนักธารเกษม (จับคู่กาพย์ยานี ๑๑ กับโคลงสี่สุภาพ)
- **คัทซีนวาดลายเส้น SVG + อนิเมชันหมึกกลับคืนในสมุดไทยขาว** ตอนผ่านแต่ละด่าน
- **เสียงพากย์ภาษาไทยครบทุกฉากและทุกโจทย์** + เอฟเฟกต์เสียงเครื่องดนตรีไทยสังเคราะห์ (ระนาดเอก ฉิ่ง ฆ้องวง)
- **รองรับทุกอุปกรณ์และเบราว์เซอร์**: iOS Safari, Android Chrome, Windows, macOS (มือถือ / แท็บเล็ต / คอมพิวเตอร์)

## โครงสร้างโปรเจกต์
```text
├── index.html          # หน้าเว็บหลัก
├── style.css           # สไตล์สมุดไทยขาว-มรกต-ทอง + Responsive
├── js/main.js          # เอนจิน 3D Three.js + วิชวลโนเวล + เสียงดนตรีไทย
├── data/gameData.js    # ข้อมูลบทเรียน ปริศนา และสารานุกรมธรรมชาติ
├── models/             # โมเดล 3D บีบอัด Draco + WebP (prince.glb, tian.glb)
├── images/             # โลโก้เกมและฉากหลังทั้ง ๔ บท
├── audio/              # เสียงพากย์บทสนทนา โจทย์ และคำใบ้
└── server.js           # เซิร์ฟเวอร์ทดสอบบนเครื่อง (Node.js)
```

## วิธีรันบนเครื่อง (Local)
```bash
npm start
# เปิดเบราว์เซอร์ไปที่ http://localhost:3000
```
